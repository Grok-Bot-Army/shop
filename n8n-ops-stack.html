Evergreen guide

An n8n Gmail to Sheets stack. Four packs. No auto-pay.

Vendor invoices and receipts sit in Gmail. Leads arrive as webhooks. This stack logs them in Google Sheets and pings Slack when a run dies. Nobody gets paid. Nobody gets a surprise email.

Invoice Inbox Receipt Inbox Lead Intake

The stack

  1. Invoice Inbox ($49). Polls Gmail for vendor invoice PDFs. Writes vendor, amount, and due date to Sheets. Status is logged, never paid.
  2. Receipt Inbox ($39). Same Gmail-to-Sheets idea for receipts you already paid. Merchant, amount, date, plus the PDF in Drive.
  3. Lead Intake ($39). One POST webhook. Typeform, Tally, Fillout, or generic JSON becomes one Sheets lead row. Never emails the lead.
  4. n8n Fail Alert ($19). One Error Trigger workflow. A failed run posts once to Slack (Telegram optional) with the execution URL.
  5. Tripwire ($29). Failed workflows write one Sheets row and ping ops Slack. Heartbeat included. Never pages clients.

That is the Gmail to Sheets n8n stack. Import what you need. Set Fail Alert or Tripwire on each live workflow so a dead poll is not silent.

What each layer writes

Layer Input Sheets row Never does
Invoice Inbox Gmail invoice PDFs Vendor, amount, due date Pay a vendor
Receipt Inbox Gmail receipt PDFs Merchant, amount, date Pay anyone
Lead Intake Form webhook JSON One flattened lead Email the lead
Fail Alert Failed n8n execution (Slack or Telegram) Spam or auto-retry loops
Tripwire Failed n8n execution Sheets row plus Slack Page clients, pay anyone

A sane order

  1. If vendor bills pile up in Gmail, start with Invoice Inbox.
  2. If SaaS receipts pile up in Gmail, add Receipt Inbox.
  3. If Typeform, Tally, or Fillout dump JSON, add Lead Intake.
  4. When any of those is live, add Fail Alert to the Error workflow slot. Want a Sheets log and a heartbeat? Use Tripwire instead.

Questions

What is an n8n Gmail to Sheets stack?

Invoice Inbox and Receipt Inbox poll Gmail PDFs into Google Sheets. Lead Intake flattens a form webhook into one lead row. Fail Alert posts once to Slack when any of those runs fail.

Does this stack pay vendors or email leads?

No. Invoice Inbox and Receipt Inbox never pay anyone. Lead Intake never emails the lead. Fail Alert only pings your ops channel.

Do I need every pack?

No. Start with the inbox that matches the file (invoices, receipts, or form webhooks). Add Fail Alert once something is live. Never Auto-Pay is optional paper before you import.
