Who it is for

Anyone who keeps pasting half a table out of an admin UI.

Copy SPA and HTML tables to Excel or Sheets

Admin UIs hide grids in divs. GridGrab reads the current Chrome tab — HTML tables, SPA / div grids, and ARIA grids — and copies TSV for Excel and Google Sheets, or CSV / Markdown. There is no row cap. It is not a Google Sheets iframe scrape, and GitHub Issues tables can miss rows.

What’s in the zip

  • The extension folder ready for Load unpacked.
  • Pro included — no license key, no free-tier gate on the Gumroad build.
  • Works offline after install. Local only.

How to start

  1. Buy and download the zip from Gumroad.
  2. Unzip it somewhere permanent (not Downloads if you empty that folder).
  3. Chrome → Extensions → turn on Developer mode → Load unpacked → pick the unzipped folder.
  4. Open the page with the table. Click the GridGrab icon. Copy TSV for Excel/Sheets, or CSV / Markdown / download .csv.

What you get

  • Finds HTML tables, SPA / div grids, and ARIA grids on the current tab.
  • Copy TSV for Excel and Sheets, CSV, Markdown, or download .csv. No row cap.
  • Click Next to merge pages, or scroll to merge infinite lists.
  • Permissions: activeTab, scripting, storage.

Limits
